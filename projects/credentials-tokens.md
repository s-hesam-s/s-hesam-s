**SabaTech**

Designed and built a .NET service to centralize financial provider credentials and token lifecycle management. Implemented token acquisition, reuse and renewal, encrypted storage, SQL-backed state, Redis caching, and account administration.

Defined service contracts and delivered the implementation, tests, and technical documentation to support integration with consuming applications.

**Core technologies:** C#, .NET, ASP.NET Core, SQL Server, Redis
