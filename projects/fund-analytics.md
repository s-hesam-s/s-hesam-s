**SabaTech**

Designed and built a .NET service for fund performance analytics, including cumulative returns, investment return calculations, and historical aggregation of fund net asset values.

Implemented domain validation, date-aware processing, and handling of incomplete historical observations. Added automated calculation tests and exposed the functionality through APIs for use by other applications.

**Core technologies:** C#, .NET, ASP.NET Core, Entity Framework Core, SQL Server
