**Course-based learning project with personal extensions**

Developed and extended a course-based .NET microservices application covering authentication, product and coupon management, shopping carts, orders, and notification workflows.

The implementation combines Ocelot API gateway routing, JWT-based authentication, Entity Framework Core persistence, and asynchronous messaging through Azure Service Bus in an e-commerce learning application with personal extensions.

**Core technologies:** C#, .NET, Ocelot, JWT, Entity Framework Core, Azure Service Bus
