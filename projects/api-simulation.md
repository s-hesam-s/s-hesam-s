Designed and built an internal platform for simulating financial market, payment, identity verification, and SMS APIs, together with a React and TypeScript administration interface.

Implemented configurable responses and failure scenarios, project and scenario management, test message inspection, and simulated payment transactions to support development and QA workflows.

**Core technologies:** C#, .NET, ASP.NET Core, React, TypeScript
